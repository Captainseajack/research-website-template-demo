RESEARCH ARTICLE TEMPLATE - START HERE
======================================

The site has four visitor pages:

1. Topic brief: /
2. Full research: /research/
3. Sources: /sources/
4. Post-publication additions: /updates/

Edit _config.yml for the site title, topic, headline, author, dates,
and GitHub Pages URL.

Edit index.html for the short article.
Edit research.md for the full article.

To add a source, copy templates/NEW-SOURCE.md into _sources/ and
rename it. Set post_publication: true when the source was found after
the article was published. It then appears automatically on Updates.

Commentary is optional. Leave commentary: "" and the website shows no
commentary heading or empty space.

Read START-HERE.md for complete instructions.
